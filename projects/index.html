DJ Library Conversion

Bridge DJ

Prepped in Rekordbox. Live in Serato.

Plug a Rekordbox-exported USB drive into your Serato machine and BridgeDJ does the rest — converting playlists into Serato crates automatically. No rebuilding playlists, no re-setting cues, no restart.

  • ✓ Auto-detect — scans every drive for a Rekordbox USB (modern or legacy database) the moment it's inserted
  • ✓ Full-fidelity conversion — tracks, playlists, hot cues, memory cues, loops, and beatgrids. Everything.
  • ✓ Serato-native output — proper .crate files and Serato Markers2 tags embedded into MP3/M4A/AIFF
  • ✓ Instant library sync — crates appear in the Files panel immediately. No restart.
  • ✓ Works alongside CDJ playback — one-shot, background daemon, GUI, or system-tray mode. The Rekordbox database is never modified.
